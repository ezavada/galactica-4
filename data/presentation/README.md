# Original presentation artwork

The splash is PICT 131 from Galactica v3 `Resources/gal-non-module.r`, converted
from its original bytes to PNG with macOS `sips`. It retains the original
Galactica A.D. logo and artwork. The source frame and SHA-256 are recorded in
`docs/reference/v3-presentation.json`. No source image content was repainted.

`sts.png` and `vendornation.png` copy the existing archived conversions of PICT
135 and 136. The source About window references these logos independently of its
credits roll. The original artwork is credited to Claudio Berni in the startup
window and About credits, alongside the original authors Edmund Zavada and
James Whitehouse. This conversion does not change the original artwork rights.

The origin narrative and credit headings are runtime-localized in the six string
resource files. Names in the original credits remain proper names. The incomplete
original music file is not used or replaced with a guessed soundtrack.
